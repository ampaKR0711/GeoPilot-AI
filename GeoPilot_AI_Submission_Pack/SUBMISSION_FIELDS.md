# Submission form field checklist

- Team name: `KRIPA` (use only if this is still the intended team name for this entry).
- Team member names: enter the actual names of all team members, comma-separated. If individual, enter the submitter's name.
- Email: use the email the form records, after checking it is correct.
- Contact email and contact number: enter a reachable contact method.
- Live API endpoint URL: **must be the real, verified public endpoint** ending in `/recommend`; never use localhost.
- Example request: use the request from `api_request_example.md` but replace the URL with the verified public endpoint.
- Hugging Face model link: verify the model card/license and whether the organizers accept the upstream model page.
- Code repository link: paste the actual public GitHub URL after publishing the source.
- Presentation: upload `GeoPilot_AI_GeoAI_Hackathon_Presentation.pdf`.
- Base model and parameter size: `Qwen2.5-1.5B-Instruct — 1.54B parameters` (verify model card details).
- Data sources/APIs: Open-Meteo Geocoding API; Open-Meteo Forecast API; Open-Meteo Air Quality API (when available).
- Confirmation: tick only if the endpoint will stay reachable for judging, model requirements are met, no prohibited hosted large model is used, and every submitted link is accessible.
